# Blue Marloc Import Module (`bm_import`)

## Overview

* **Type:** module
* **Description:** Support for importing content
* **Package:** bluemarloc
* **Core version requirement:** 9.x
* **Dependencies:** `drupal:field`

Detailed functionality analysis exists in the Drupal 11 equivalent or contributed modules. This page focuses on the custom implementation details required when working with the Drupal 9 codebase.
